Лабораторная работа 1: граф терминов металлургии 

Программа собирает тексты с страниц Википедии и отраслевых сайтов по металлургии, извлекает ключевые термины и строит граф их совместной встречаемости.
Узлы — термины, рёбра — случаи, когда термины встречаются на одной странице (не менее K раз).
Результат сохраняется в формате .dot для визуализации в онлайн-вьюерах Graphviz.
Также выводится топ-15 терминов по числу связей.
